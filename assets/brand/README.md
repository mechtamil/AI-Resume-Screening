# ALTEN brand assets

Place communication-approved ALTEN logo files here when the application is
deployed inside the organisation:

- `alten_logo_black.png` for light backgrounds
- `alten_logo_white.png` for dark or coloured backgrounds

RecruitOS falls back to the official public ALTEN media-library URLs when these
files are not present. Do not edit, recolour, crop, rotate, distort, or add
effects to the logo.
